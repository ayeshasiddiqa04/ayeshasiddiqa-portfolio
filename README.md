# Ayesha Siddiqa Portfolio

A modern personal portfolio website built with HTML, CSS, and JavaScript. It includes:

- Hero and about section
- Skills and experience timeline
- Featured project cards with filtering
- Contact form with email fallback
- SEO-friendly metadata and responsive design

## Run locally

From the project folder:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Contact form

The form tries to send through FormSubmit using the default address `hello@ayeshasiddiqa.dev` and falls back to opening the user's email app if the network request cannot complete. Replace the address with your real email to receive notifications.

## Customize

Update the text, skills, and project details in `index.html` to match your exact resume and job profile.
